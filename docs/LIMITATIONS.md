# Обмеження (чесно)

## Перевірка

- **Залізо не тестувалось.** Усі нативні перевірки виконано на емуляторі fm1-emu (справжній `.fwsc`, емульований CPU PI32v2, LCD, матриця клавіш, UART MIDI, аудіо). Прошивку **не записано** на жоден FM-1 — це робить власник, свідомо, через офіційний updater / workbench, з резервною копією.
- Звук оцінено вимірюваннями (RMS, піки, спектральний баланс, відсутність кліпінгу), а не прослуховуванням на реальних динаміках. Тембри DX7 (бас, орган, EP, духові) запрограмовано з нуля і варто дослухати й підкрутити на пристрої.
- Тип TRS (A/B) гнізда MIDI IN FM-1 офіційно не задокументовано; фізичне з'єднання з Vortex не перевірено.
- Пресет для Alesis Vortex Editor не згенеровано файлом: формат `.vw2` закритий. Дано точну таблицю і покрокову інструкцію + JSON-довідку.

## Ресурси FM-1

- Ліміт застосунку в пакеті — 453 921 байт. Щоб умістити RIDDIM ROOTS, керувальний код скомпільовано з `minsize`, лев зберігається RLE (1790 байт), а **128-голосний заводський банк DX7 M-VAVE не лінкується** (замінено одним заводським голосом для Program Change на DX7-доріжках). Це не впливає на звуки RIDDIM ROOTS (усі патчі власні), але бібліотечні програми DX7 зі стокової прошивки недоступні.
- 8 доріжок SDK: 6 для бенду + 2 для живої гри. Тому **перкусія ділить 808-кіт з барабанами** (окремий мотив і рівень частин, але одна велосіті на крок), а **piano/organ/horns** — це три окремі доріжки, без окремої доріжки для «lead synth» (він — один зі звуків HORNS/LIVE).
- Сирена, ейрхорн, лазер, шум, bass drop — синтезуються в майстер-шині; вони не проходять через reverb SDK (мають власну стрічкову луну).
- Tape stop / rewind / stutter працюють з історією майстра 0,37 с (16384 семпли, моно під час ефекту) — це обмежена симуляція, не справжнє «перемотування» довгого запису.
- Delay і reverb — алгоритми SDK (один на всіх) з per-track sends; окремої спружинної моделі немає (SPRING = короткий reverb + snare send).
- Таймінг нот — сітка шістнадцяток секвенсора SDK + swing; мікротаймінгу між кроками немає.
- Зміна стилю/звуку застосовує тембр доріжки через `groove_timbre_apply` — нота, що звучить на цій доріжці, може обірватися (на межі такту).
- LOAD/SAVE FLASH на мить глушить звук (SDK під час запису флешу); LOAD може перезапустити транспорт.
- MIDI Clock ігнорується: RIDDIM ROOTS завжди майстер темпу (Start/Stop приймаються).
- Запис DNA у флеш вміщує 312 байт; якщо мотивів забагато, менш важливі (HORNS, PERC, FX) регенеруються при завантаженні.
- Вихідного MIDI на Vortex немає (FM-1 TRS — лише вхід), тож мотора/LED-зворотного зв'язку немає; працює soft takeover.

## Браузерне демо

- Потребує швидкого ПК: емуляція 240 МГц у WebAssembly. Якщо тріщить — менший Clock на повній сторінці емулятора або закрити DevTools.
- Дуже короткі кліки мишкою по кнопках інколи коротші за цикл опитування прошивки; утримуй кнопку довше або користуйся клавіатурою ПК.
