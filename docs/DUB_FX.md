# DUB FX LAB

Маршрут сигналу: **ІНСТРУМЕНТИ → мікшер SDK (рівні, per-track sends) → delay/reverb SDK → майстер-шина RIDDIM (rr_fx) → master/USB/BT**.

`src/fw/rr_fx.c` виконується в аудіо-перериванні, у внутрішній SRAM (перевіряється збіркою), у фіксованій точці, без ділення на семпл і без алокацій. Керування — через поштову скриньку без блокувань (16 команд) і атомарні параметри.

## Автоматика і людина

Дабовий інженер (компонент FX рушія) розставляє дії в такті: echo throw, сирена, spring, шум, лазер, filter sweep, feedback. Ручні дії мають пріоритет: якщо ти чіпав параметр (фільтр, sends, feedback, reverb) за останні N секунд (MIDI → K4, 4 с за замовчуванням), автоматика його не чіпає, генеративний стан не руйнується. Momentary-ефекти завжди відпускаються на Note Off / відпусканні кнопки.

## Безпека

DC-блокер, тепла сатурація вище −6 dBFS, **лімітер** з блоковим look-ahead (стеля 0,95 FS, миттєва атака, плавне відновлення), обмеження фідбеку ≤ 0,92 (burst ≤ 0,96, з м'яким кліпом у записі), насичувальна арифметика (нема денормалів — фіксована точка), межі буферів масками. Якщо SDK фіксує underrun/overrun — вимикаються найважчі insert-ефекти (phaser/chorus/flanger/crush), фільтр і голоси лишаються («CPU: FX REDUCED»).

Перевірено в емуляторі: 0 underrun/overrun за весь приймальний сеанс; нуль кліпінгу у записах стилів.
