# Безперервні переходи стилів і темп

**Зміна стилю ніколи не потребує STOP.** Аудіорушій і транспорт секвенсора не зупиняються; рушій перебудовує музику по компонентах на межах тактів.

| Стиль | BPM (діапазон) | Характер |
|---|---|---|
| SKA | 150 (130–175) | upright bass walking, оф-біт гітара, trumpet, SKA-кіт |
| ROCKSTEADY | 96 | ворд-бас, bubble орган, cross-stick 2&4, brass |
| ROOTS | 72 | one drop, глибокий E.BASS, гітарний скенк, орган, melodica |
| STEPPERS | 78 | four-on-floor kick, sub bass, double skank, сирени |
| DUB | 70 | розріджено, довгі суб-ноти, ехо-кидки, high DUB |
| RUB-A-DUB | 84 | FM bass, digital organ, clavinet |
| DANCEHALL | 96 | dembow / sleng-подібні патерни, digi bass, різкі стаби |
| RAGGA JUNGLE | 164 | брейк-біти шістнадцятками, бас і скенк у половинному часі |

## Режими переходу (STYLE → K2) і довжина (K3: 1, 2, 4, 8, 16 тактів)

| Режим | Що відбувається |
|---|---|
| SMOOTH | компоненти переходять по черзі на межах тактів: FX → PERC → ORGAN → PIANO → HORNS → HARMONY → DRUMS → SKANK → ARRANGE → BASS (бас останнім) |
| DUB MIX | перша половина: ехо-кидки, скорочення до барабанів і басу; друга половина — нові партії входять по одній, бас останнім |
| BREAK | у передостанньому такті — філ, потім усі нові партії разом |
| HARD SWITCH | усе на наступній межі такту (миттєвий темп дозволено, бо явно обрано) |
| MUTANT | компоненти перескакують у новий стиль у випадкові такти — гібрид старого й нового, поки перехід не завершиться |

Заморожені компоненти не перегенеровуються — вони отримують новий стиль як «дім» (регістр, тембр), зберігаючи мотив. Тест: замороджений бас ROOTS → DUB TECHNO лишився тим самим мотивом.

Новий вибір під час переходу перенацілює його з поточного місця (тест: ROOTS→JUNGLE→ROOTS→SKA).

## Темп

План обирається автоматично (`rr_engine_style`):

- **Плавний розгін** — якщо співвідношення темпів < 1,6: лінійно по тактах переходу.
- **Double-time** (цільовий ≥ 1,6× поточного), напр. ROOTS 72 → RAGGA JUNGLE 164: спершу розгін до половини цілі (82), бас і скенк переходять у половинний час, потім на межі такту темп стрибає до 164 — **сприйнятий пульс не змінюється**, брейк-біт вмикається вже у справжньому темпі.
- **Half-time** (≤ 0,625×), напр. 164 → 72: спершу стрибок на половину (82) з подвоєнням довжини нот у компонентах, далі плавно до 72.

Емулятор (нативна прошивка): STEPPERS 77 → DUB TECHNO через 61 і стрибок на 122; DUB TECHNO 122 → JUNGLE 164; JUNGLE → ROOTS 72 — усе без зупинки, аудіо RMS > 0 кожні 0,5 с.

## Пряме керування BPM

- ALGORITHM — ±1, HOME+ALGORITHM — ±5, REC — tap tempo, MIDI CC3 (50–200 за замовчуванням, межі на SYSTEM).
- SMOOTH (за замовчуванням): темп іде до цілі кроками ~90 мс (1 + різниця/12 BPM), що прибирає дрижання від CC. INSTANT: одразу.
- Темп змінюється функцією SDK `groove_tempo_edit` без перезапуску аудіо; позиція секвенсора і запис тактів наперед лишаються синхронними.
