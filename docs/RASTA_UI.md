# Rasta UI і анімований Лев Юди

## Візуальна мова

Чорне тло, глибокий зелений, золото, червоні акценти, білий текст. Триколірна смуга червоний/золото/зелений угорі кожної сторінки. Великі цифри BPM, кольорові метри EVOLVE/ENERGY/DUB, «чипи» бенду (зелений = грає в цьому такті, крижаний з рамкою = заморожений).

## Лев

Джерело — наданий піксель-арт (`assets/lion/lion_source.webp`). `tools/lion_assets.py` знаходить межі малюнка, бере домінантний колір центру кожної клітинки піксельної сітки (різкість без змазування), мапить у курровану палітру з 15 кольорів оригіналу + прозорість. Результат: **100 × 88**, 4 біти/піксель, **RLE 1790 байт** у флеші, один раз розпаковується в 4400 байт RAM.

Анімація — без кадрів-копій: трансформації зон спрайта під час рендерингу:

| Зона | Рух |
|---|---|
| голова + корона (x≥60, y<60) | кивок, трясіння, нахил назад, підйом голови |
| прапор (x<53) | хвиля, амплітуда росте від древка; древко нерухоме |
| хвіст | розгойдування в ритм |
| тіло | підскок на ударах бочки |
| грива | вібрація темних пікселів у FX-режимі |
| очі | накладки: відкриті «здивовані», лінії сну, моргання |

| Подія | Поведінка | Тест (емулятор) |
|---|---|---|
| PLAY | кивок у такт (фаза кроку секвенсора), підскок на бочку | ≥3 різні пози за 2,8 с |
| STOP | лев спить: голова опущена, очі-лінії, «Z Z» | режим SLEEP |
| MUTATE | трясіння головою, відкриті очі, «!» | MUTATE |
| DUB FX | моргання, сильна хвиля прапора, вібрація гриви, хвилі луни | FX |
| FREEZE | поза фіксується точно, сніжинки | хеш пікселів лева незмінний 400 мс |
| DROP | відкидається назад, очі закриті | DROP |
| STYLE CHANGE | танець усім спрайтом весь перехід | DANCE |
| MIDI INPUT | дивиться вгору пропорційно velocity, нота-символ | MIDI |

HOME — повний лев; інші сторінки — 50 × 44 мініатюра (децимація того ж буфера) у заголовку.

## Продуктивність

- Кадр складається смугами по 16 рядків у два буфери по 7,5 КБ; хеш кожної смуги порівнюється з попереднім кадром — **на LCD відправляються лише змінені смуги** (DMA SDK, неблокуюче). Повноекранного перемальовування немає.
- ~14 кадрів/с, не більше 3 смуг за виклик керувального циклу; аудіо від UI не залежить (UI в керувальному потоці, DSP у перериванні).
- Анімація синхронізована з позицією секвенсора й подіями рушія, без спектрального аналізу.
- Виміряно в емуляторі: див. `docs/TEST_REPORT.md` (пікселів/с у STOP і PLAY, 0 underruns).

Шрифт 5×7: цифри й літери — з панельного шрифту M-VAVE FM1 Open (GPL-3.0); символи — нові.
